# 下一阶段改进清单（草案 v1）

> 现状：模拟内核已经很厚（社会层 / 信息层 / 目标决策 / 武器 / 感染 / 混乱度 / 时间），
> **但"玩"的部分还很薄**。这一份只讨论"还能加什么"，不写实现。

---

## 一、最缺的一块：玩家在玩什么

现在整个系统是"看戏"：调参数、点工具、看城市崩。**没有目标，没有输赢，没有取舍。**

| 想法 | 说明 | 代价 |
|---|---|---|
| **撤离目标** | 玩家扮演"应急指挥"，目标是把**撤离人数**最大化，或撑到第 N 天 | 低 |
| **结算评分** | 战报已有，加一张评分卡：撤离 / 死亡 / 感染 / 警力消耗 / 预算剩余 | 低 |
| **预算经济** | 现在经费 100 万只出不进；改成按"撤离人数/存活人口"给回款 | 低 |
| **阶段任务** | 每天一个目标（第 1 天：封锁 3 个路口；第 2 天：护送要员…） | 中 |
| **难度档** | 四个滑块打包成 简单/普通/噩梦（爆发规模 × 潜伏期 × 警力 × 免疫率） | 低 |

> **我认为这是当前最高优先级。** 不管模拟多细，没有目标就只是"沙盘表演"。
> 而这一块的成本意外地低 —— 只需要在 `report.js` 加评分、在参数面板加难度档。

## 二、个体与群体：让人更像人

| 想法 | 为什么值得 | 代价 |
|---|---|---|
| **谣言与信息失真** | 电话链每传一次，信息就歪一点："有丧尸"→"有怪物"→"政府在撒谎"。人群按**错误信息**行动（跑错方向、涌向错误地点）。**这是信息层的天然延伸，而且极出戏** | 中 |
| **误认** | 近距离、遮挡、恐慌时，把"受伤的人"当成丧尸 → 误报、踩踏、误杀 | 低 |
| **拥堵与踩踏** | 警局门口、撤离点、医院门口人群密度超标 → 速度骤降、零星死亡 | 低 |
| **喊叫** | 平民大喊会吸引丧尸、也会召集附近的人（和枪声同一套噪音系统） | 低 |
| **门与锁** | 门可开/可反锁 → "把人锁在门外"这种社会化行为才成立 | 中 |
| **伤病** | 抓伤/摔伤（不感染）→ 移动变慢、需要去医院 → 医院除了感染还有别的队伍 | 低 |
| **抢劫 / 纵火 / 私刑** | 混乱度高的区域自发出现；巡警在场才能压住 | 中 |

## 三、城市本身：让它会"坏掉"

| 想法 | 为什么值得 | 代价 |
|---|---|---|
| **分区停电** | 夜里某些街区全黑（配合已有的昼与夜光照，观感直接拉满）；医院靠备用电源撑一会儿 | 低 |
| **通讯中断** | 电话链传播速率骤降、警局电台失效 → 报警不再自动出警 | 低 |
| **供水污染** | 零号病人的源头之一；也是一条"看不见的传播" | 低 |
| **道路堵塞** | 弃车堵路 → 撤离路线上出现瓶颈（和拥堵联动） | 中 |
| **楼层 / 室内结构** | 现在只有"室内"二元；加"上楼/地下室"才有"躲进去"的真实感 | 高 |

---

## 四、医疗与防控：给玩家更多手段

| 想法 | 为什么值得 | 代价 |
|---|---|---|
| **筛查 / 检疫站** | 军队设卡，只出不进、测体温 → 潜伏者会被拦下（玩家不可见，只能看"排队异常"） | 中 |
| **疫苗产能** | 研发进度 + 每天只能救 N 人 → 变成"救谁"的取舍 | 中 |
| **医院分流** | 爆发后医院"封院"拒绝接收 → 门口聚集（已有雏形，加"拒绝"这一步） | 低 |
| **隔离区** | 用路障围出区域，里面的人出不来（工具已有，加"区域"概念） | 中 |

---

## 五、表现层：让判断变快、让情绪到位

| 想法 | 为什么值得 | 代价 |
|---|---|---|
| **血迹 / 尸体 / 火光 / 烟** | 2D 精灵层加几帧，画面信息量翻倍 | 低 |
| **咳嗽声** | 发病者的听觉线索（不看面板也能听出"这片有人在发烧"） | 低 |
| **导演镜头** | 关键事件（第一个要员死、警局失守）短暂聚焦 2 秒 | 低 |
| **热力图叠层** | 感染密度 / 人群密度 / 混乱度曲线 | 低 |
| **事件时间轴** | 战报里已经有文字；做成可拖动的时间轴回放 | 高 |

## 六、内容与规模

| 想法 | 说明 | 代价 |
|---|---|---|
| **更多城市** | 现在 5 个；POI 推断已通用，加城市只要跑烘焙 | 低 |
| **城市特征** | 水域（桥是瓶颈）/ 地铁（地下传播）/ 高层 / 县城（镇平：楼极少） | 中 |
| **封闭场景** | 地铁站、机场、商场、学校 —— 一张小图，密度极高 | 中 |
| **剧本模式** | 固定地图 + 固定开局时间 + 固定目标（"守住医院 8 小时"） | 中 |

## 七、优先级（价值 × 代价）

| 排名 | 项目 | 价值 | 代价 | 为什么排这里 |
|---|---|---|---|---|
| 1 | **撤离目标 + 结算评分 + 预算回款** | ★★★ | 低 | 让游戏第一次"有输赢" |
| 2 | **谣言与信息失真** | ★★★ | 中 | 信息层的天然延伸，出戏，且和"信任"属性直接挂钩 |
| 3 | **拥堵与踩踏** | ★★ | 低 | 便宜，但画面和叙事冲击极大（撤离点变绞肉机） |
| 4 | **分区停电 + 通讯中断** | ★★ | 低 | 把已有的昼夜光照变成玩法（夜里没灯 = 看不见 = 更危险） |
| 5 | **筛查/检疫站** | ★★★ | 中 | 给玩家一个"主动防疫"的工具，而不只是被动救火 |
| 6 | 交通（车） | ★★★ | 高 | 最大的缺失块，但一动就要改寻路、碰撞、渲染 |
| 7 | 楼层/室内结构 | ★★ | 高 | 需要改烘焙和碰撞层，收益主要在"躲藏"的真实感 |

## 八、如果只做三件事

1. **给游戏一个目标**（撤离人数 + 评分卡 + 预算回款）—— 半天的工作量，改变整个体验。
2. **谣言系统**（信息在电话链里失真）—— 复用现有信息层，输出一个"人群往错误方向跑"的新现象。
3. **拥堵与踩踏** —— 复用空间哈希，几十行代码，撤离点和警局门口立刻变成"会死人的地方"。

这三件做完，游戏就从"能看"变成"能玩"，而且都不需要动内核结构。

---

## 九、需要你选方向

1. 先做**玩法目标层**（评分/预算/任务），还是先做**系统深化**（谣言/踩踏/停电）？
2. **交通（车）**要不要提上日程？它是最大的一块，但会牵动寻路与碰撞。
3. **封闭场景**（地铁站/商场）要不要做一张试验图？它比"再来五个城市"更能体现模拟密度。
4. **剧本模式**（固定地图 + 固定目标）是否是你想要的"关卡感"？
