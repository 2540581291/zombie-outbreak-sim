# 个体性格系统设计（v4 · 含审计 / 溯源 / 日常层 / 三步链 / 时间系统）

> 四个属性，0–100，决定**同一个人在同样处境下会做什么**。
> 目标不是"给每个人加四个数字"，而是让**同一场爆发里出现完全不同的反应**：
> 有人冲去警局、有人回家接孩子、有人抢枪、有人装死、有人弃岗。

---

## 一、四个属性

| 属性 | 行为学含义 | 高（80+） | 低（20−） |
|---|---|---|---|
| **政府信任度** | 相信"体制会处理"的程度 | 听广播、去警局/医院、配合疏散、上交武器、等救援 | 自己拿主意、不信警察、囤货、抢、提前跑 |
| **家庭责任** | 把家人放在自己前面的程度 | 先回家、接孩子、带家人一起走、家人死了会崩 | 只顾自己、抛下同伴、独自逃离 |
| **意志坚定** | 压力下守住目标的能力 | 不因恐慌改主意、能固守、能组织别人、慢性子 | 一有风吹草动就改目标、僵住、跟人群走 |
| **勇猛无畏** | 愿意靠近危险的程度 | 拿枪、救人、引开丧尸、守最后一道线 | 躲、装死、绕远路、看见血就软 |

### 关键设计：属性不是常数

**有效值 = 基准值 × 环境修正**，这样"人设"会被局势改变：

```
有效政府信任 = 信任 × (1 − 混乱度/160)     ← 混乱越高，越不信体制
有效家庭责任 = 责任 × (家人死亡 ? 0.5 : 1)   ← 家破人亡后会变得只顾自己
有效意志     = 意志 × (1 − 恐慌×0.3)        ← 恐慌上头时意志打折
```

于是同一批人，**开局和崩溃后期是两种行为模式** —— 这比"随机数抽一次定终身"有意思得多。

### 警察

警察多一列：**职责**（临时量 = 政府信任 × (1 − 混乱/120)），
因为"体制值不值得卖命"和"我敢不敢"是两件事。

| 目标 | 政府信任 | 家庭责任 | 意志 | 勇猛 |
|---|---|---|---|---|
| 出警 / 护送 | +0.60 | 0 | +0.40 | +0.30 |
| 设卡 / 疏散 | +0.55 | 0 | **+0.65** | +0.25 |
| 镇压抢劫 | +0.70 | 0 | +0.35 | +0.40 |
| 回局坚守 | +0.50 | 0 | **+0.80** | +0.35 |
| **弃岗回家** | **−0.90** | **+0.95** | **−0.50** | −0.20 |

**最戏剧化的一条**：`家庭责任 90 + 政府信任 20 + 意志 30` 的警察会在混乱 40% 左右
**脱掉制服往家跑**，变成带枪平民。这比"所有警察都英勇"真实得多，也给玩家制造难题：
警力是有限的，而且**会流失**。

| 目标 | 政府信任 | 家庭责任 | 意志 | 勇猛 |
|---|---|---|---|---|
| 等待护送 / 配合 | **+0.90** | 0 | +0.30 | 0 |
| 要求增援 | **+0.85** | 0 | +0.25 | +0.10 |
| 自行逃离 | **−0.85** | 0 | +0.45 | +0.25 |
| 隐瞒身份 | **−0.70** | −0.30 | **−0.40** | −0.30 |
| 征用资源 | **−0.75** | −0.20 | +0.30 | **+0.55** |

要员的**家庭责任影响很小**（他们是"公共人物"设定），但低信任 + 低意志会让他
**藏着不露面**，护送队到了也找不到人 —— 这条很有意思，值得做。

## 四、决策公式

```
U(目标) = Σ_attr ( 有效属性ᵢ × 系数[目标][i] )
        + 处境项（危险度、距离、知晓度、混乱度、家庭存活）
        + 噪声
        × 角色权重
```

角色权重保证"同一个属性在不同人身上推的方向和力度不同"：

| 属性 | 平民 | 警察 | 要员 |
|---|---|---|---|
| 政府信任 | 1.0 | 0.8 | 1.2 |
| 家庭责任 | 1.0 | 0.8 | 0.3 |
| 意志 | 1.0 | 1.2 | 0.9 |
| 勇猛 | 1.0 | 1.1 | 0.6 |

（要员更吃信任，警察更吃意志，勇猛对要员几乎没用 —— 他们不亲自打。）

再加三条**硬规则**，避免"分数打架"：

1. **意志 < 15 且危险 > 0.6** → 直接进入"僵住"（站着不动 10 秒），不参与打分；
2. **勇猛 < 10** → 永不选择需要靠近危险的目标（救人、引开、抢武器、民兵）；
3. **政府信任 > 70 且混乱 < 30** → 优先服从（去警局/疏散），哪怕离家更远。

## 六、和现有系统的交叉

| 现有系统 | 交叉点 |
|---|---|
| **混乱度** | 稀释政府信任（越乱越不信）；同时是"体制行为"的开关（≥50 才没人管） |
| **信息层** | 属性只决定"知道之后怎么反应"；不知道时还是照常上班 |
| **家庭** | 家人存活数直接乘进家庭责任；家人全灭 → 责任减半、信任掉 20 |
| **武器/军械库** | 勇猛决定敢不敢用；信任决定违不违法（信任高的人不抢，会去警局要） |
| **护送** | 要员信任高 → 老实等护送；低 → 自己跑/藏起来（护送队白跑一趟） |
| **警察编制** | 弃岗会让警局驻警**真实减少**，出警能力随之下降 |

## 七、属性怎么生成

不是纯随机，否则"人设"和"职业/年龄"对不上：

| 人群 | 政府信任 | 家庭责任 | 意志 | 勇猛 |
|---|---|---|---|---|
| 平民（基准） | 50±18 | 60±20 | 50±18 | 45±20 |
| 老年人 | **+15** | +10 | +5 | **−15** |
| 青年人 | −10 | −10 | +5 | +10 |
| 有未成年子女 | +5 | **+25** | +5 | 0 |
| 警察 | **+15** | 0 | **+20** | **+15** |
| 要员 | **+30** | −15 | +10 | −10 |
| 教师 / 公务员 | +15 | +5 | +5 | −5 |

再叠一点个人噪声（±10），保证同类人里也有差异。

## 十、一致性审计：属性 × 行为的冲突与裁决

> 我自己把上面那套映射算了一遍，找出 **13 处会打架的地方**。不修的话，
> 表现会是"这个人明明很爱家，却在原地发呆"这种说不通的场面。
> 每条都给裁决，写进实现里。

### A. 打分结构引发的（4 条）

**A1. 分数可能全为负 → 站在街上发呆**
`逃出城` 对"信任 5 / 责任 5 / 意志 5"的人是三项小幅负 + 一项 0 ≈ 0，
而其它目标也 ≈ 0，argmax 选出一个"什么都没意义"的结果。
> **裁决**：每个目标带一个**基线常数**（逃 0.35 / 回家 0.30 / 固守 0.25 / 警局 0.20 …），
> 属性只做加减；并且**兜底规则**：如果所有目标都 < 0.15，一律按"逃"处理 ——
> 求生是本能，不需要理由。

**A2. 多条 +0.8 项叠加 → 永远同一个目标赢**
一个"信任 90 / 责任 95 / 意志 90 / 勇猛 85"的人，六七个目标都被推到 1.5+，
排序全靠噪声，行为变成随机的。
> **裁决**：属性项先**归一化**（除以该目标的系数绝对值之和，落在 −1..1），
> 再乘 0.6 与处境项相加。属性只决定**偏向**，处境决定**具体**。

**A3. 同一目标被两个属性推向相反方向**
`逃出城` = 信任 −0.55、责任 −0.25、意志 +0.20 —— 一个"低信任 + 高家庭"的人
两边抵消，逃与不逃各一半。
> **裁决**：这类目标改为**门槛式**：属性只决定"能不能选"（信任 > 60 不选逃；
> 家人全活时责任 > 80 不选逃），不再靠加权抵消。

**A4. 混乱度稀释信任 → 半路改主意**
信任 70 的人在混乱 45% 时有效信任掉到 50，行为可能从"去警局"直接翻成"回家"，
在街上看到的现象就是**走走停停、来回横跳**。
> **裁决**：沿用现有承诺机制（换目标后 8–14 秒不改），并加**跨类翻转门槛**：
> 新目标必须超过当前目标 0.15 分才准换；同类的微调不重置承诺计时。

### B. 属性组合引发的（5 条）

**B1. 意志低 + 信任高 → "僵住"和"服从"打架**
`僵住`（意志 < 15）与 `服从疏散`（信任 > 70）同时成立，逻辑上矛盾。
> **裁决**：僵住加一个前提 —— **周围没有秩序**。即
> `意志 < 15 && 危险 > 0.6 && (混乱 > 40 || 有效信任 < 60)` 才僵住。
> 有人在组织疏散时，胆小的人会跟着走，而不是石化。

**B2. 家庭责任 95 + 信任 90（慈父 + 模范市民）→ 回家还是去警局？**
两条都拿高分，结果在两个目标之间反复。
> **裁决**：引入**链式目标**（这是本版最重要的补充）：
> `接家人 → 带去警局`、`接家人 → 一起逃`。
> 判定：责任 > 70 且信任 > 70 → 目标 = `HOME`，到达后自动接续为 `SHELTER`；
> 责任 > 70 且信任 < 40 → 到达后接续为 `FLEE`。链式目标记为一个，不参与重复打分。

**B3. 意志高 + 勇猛极低（胆小但倔强）→ 想回家却不敢动**
`固守` 拿高分，但 `躲藏` 也接近（勇猛低会推向躲藏），人卡在两者之间。
> **裁决**：意志 ≥ 60 时，勇猛低只影响**移动速度**（沿墙绕行、慢 30%），
> 不否决"回家/固守"。躲藏只对"意志 < 40 且勇猛 < 25"开放。

**B4. 勇猛 < 10 的硬规则 vs 逃命**
硬规则说"永不选需要靠近危险的行为"，但逃跑路线可能穿过尸群。
> **裁决**：硬规则只作用于**主动**行为清单（救人、引开、抢武器、民兵、抢物资），
> 不作用于移动路径。逃命属于"不得不"，照样跑。

**B5. 要员"征用资源"要求勇猛，但全体要员勇猛 −10**
按公式这条几乎永远不会触发，等于白写。
> **裁决**：征用改由**低信任 + 高意志**驱动（"我比你更有资格用这辆车"），
> 勇猛只做 +0.15 的小加成。

### C. 行为之间引发的（4 条）

**C1. 抢别人武器 / 救人：目标不存在时怎么办**
附近没人有枪、也没人被围，行为却可能被选中 → 人跑到空地上做奇怪的事。
> **裁决**：这两条加**前置条件**（半径 40m 内存在"有枪的人" / "被围的人"），
> 不满足则不进候选集。

**C2. 警察"弃岗"与"护送/出警中"冲突**
正在护送要员的警员突然弃岗，要员半路没人管。
> **裁决**：弃岗只评估**待命/巡逻**状态；一旦进入出警或护送，视为**已承诺**，
> 任务结束（或失败）后才会重新评估。

**C3. 要员"隐瞒身份"与"自行逃离"互斥**
两条都靠低信任驱动，可能同时入选，表现是"又躲又跑"。
> **裁决**：用**门槛互斥**而不是分数互斥：
> 隐瞒（信任 < 35 且意志 < 45 且勇猛 < 40）优先；不满足再看自行逃离。
> 隐瞒期间**不参与护送**（护送队会扑空，这是有意设计的）。

**C4. "发表讲话"与混乱度公式的冲突**
讲话能让周围 panic 下降，但混乱度是宏观统计，若被单人言论撬动会很怪。
> **裁决**：讲话只影响**附近 30m 内的 panic 与知晓度**，
> **不进入混乱度公式**。混乱度只由"知情率 + 感染率"两个宏观量决定，这点不动。

### D. 审计之后要写进代码的三条硬约束

1. **单一事实来源**：`decide()` 与"行动溯源"必须调用**同一个打分函数**，
   否则面板会显示一套、行为是另一套（这是最容易出的错）。
2. **属性只做偏置，不做否决** —— 唯一的否决是"前置条件不满足"（C1）和"已承诺"（C2）。
3. **每次行为翻转都要能解释**：翻转原因必须落到某一条分数或某一条规则上。

## 十一、行动溯源：为什么这个人现在在做这件事

> 你提的这条我认为是整个系统最关键的"可读性"设计 ——
> 没有它，属性系统就是个黑箱，玩家只会觉得"这帮人乱走"。

### 面板上的样子

选中一个人，档案面板底部多一块「**当前行动**」（可以折叠）：

```
当前行动：去警局避难          总分 0.82
第二名：  回家 0.71           （差 0.11 —— 接近，随时可能改）

打分构成
  基线                      +0.20
  政府信任 82 × 0.85        +0.70   ████████
  意志     55 × 0.15        +0.08   █
  勇猛     30 × −0.10       −0.03   ▎
  危险度 0.40 × 0.55        +0.22   ██
  距离 180m                 −0.15   █
  混乱度 62%                ×1.10   （放大"体制类"目标）
  ─────────────────────────────────
  小计                       0.82

触发的规则
  · 混乱度 ≥ 50% → 平民优先去警局避难
  · 勇猛 < 10 未触发（30）
排除的行为
  · 救人（50m 内没有被围的人）
  · 抢武器（50m 内没有持枪的人）
```

各块的含义：

| 块 | 作用 |
|---|---|
| **当前 vs 第二名** | 一眼看出"稳不稳"，差 < 0.1 就是在摇摆边缘 |
| **打分构成** | 每一项的**具体数值与贡献**，正绿负红 |
| **触发的规则** | 命中/未命中的硬规则（僵住、勇猛否决、混乱门槛） |
| **排除的行为** | 因为前置条件不满足而**根本没进候选**的行为，附原因 |

### 数据从哪来

**不要存历史**（20k × 每人 10 项 = 内存爆炸），而是**按需重算**：

```js
sim.explain(i) → {
  goal, total,
  alts: [{ goal, score }],          // 前三名
  terms: [{ k, label, value, coef, contrib }],
  rules: [{ text, hit }],
  excluded: [{ goal, why }],
  changedAt, changedReason,          // 上一次为什么换目标
}
```

- `decide()` 内部先调 `scoreGoals(i)` 拿到全部候选与分项；
- `explain(i)` **调同一个** `scoreGoals(i)`，把分项原样返回；
- 面板只在**选中一个人**时调用一次（1 次/帧最坏，成本可忽略）。

这样"显示的就是真跑的"，审计 A1–C4 也能在面板上直接验证。

### 顺带的一个副产品

因为每个决定都能解释，**调参不再靠猜**：
改一个系数 → 看一批人的"当前行动"分布怎么变 → 立刻知道这刀削哪儿了。
这比跑回归测试直观得多。

## 十二、更新后的决策公式（v2 定稿）

```
score(目标) =
    基线[目标]                       ← 常数，保证兜底
  + 0.6 × Σ ( 有效属性ᵢ × 系数[目标][i] ) / Σ|系数[目标]|   ← 归一化，避免叠加爆表
  + 处境项（危险度 / 距离 / 知晓度 / 混乱度 / 家人存活）
  + 噪声 ±0.05

硬规则（先于打分）
  前置条件不满足 → 不进候选（C1）
  已承诺任务中   → 不评估弃岗/重大转向（C2）
  意志 < 15 且危险 > 0.6 且无秩序 → 僵住（B1）
  勇猛 < 10 → 主动危险行为直接排除（B4 限定的那 5 条）

选择
  argmax(score)
  跨类翻转需超前 0.15 分（A4）
  全部 < 0.15 → 逃（A1）
```

## 十五、日常行为层（正常生活）· 依赖第十九节的时钟

> 之前的设计只写了"出事之后怎么办"。但游戏开局有一大段时间是**正常生活**，
> 而且"没听说"的人本来就该照常上班、上学、看病 —— 这层要有独立的优先度。

### 两层决策

```
日常层（D）：awareness == 0 且 chaos < 15 且 没亲眼看见丧尸
过渡带：     chaos 15–35，日常行为概率线性下降（每 +1 混乱 −5%）
危机层（C）：awareness ≥ 1 或 chaos ≥ 35 → 走性格驱动的那套
```

日常层**不看性格**（性格只做小幅修正），看的是**日程**：

| 时段 | 行为 | 优先级 |
|---|---|---|
| 07:00–09:00 | 通勤（家 → 单位 / 学校） | 高 |
| 09:00–12:00 | 在单位 / 在学校 | 高 |
| 12:00–13:00 | 午饭（超市 / 街边店） | 中 |
| 13:00–17:00 | 在单位 / 在学校 | 高 |
| 15:00–16:00 | **接孩子**（家庭责任 > 60 且有未成年子女） | 高 |
| 17:00–19:00 | 回家 | 高 |
| 19:00–22:00 | 购物 / 散步 / **看医生** | 中 |
| 22:00–07:00 | 在家睡觉 | 高 |
| **任何时段：生病（普通病，非感染）** | **去医院** | **最高**（压过上班） |
| 周末 | 购物 / 公园 / 在家 | 中 |

### "不肯上班"的几种情况（性格在这里只做小幅修正）

| 属性 | 修正 |
|---|---|
| 家庭责任 > 70 | 下班直接回家，晚上不闲逛（购物概率 ×0.5） |
| 家庭责任 > 70 且有孩子 | **自动接送孩子**（15:00 去学校，16:00 带孩子回家） |
| 意志 < 30 | 翘班概率 +20%（在家赖着或在街上晃） |
| 政府信任 > 70 | 准时上班，迟到/翘班概率 −50% |
| 勇猛 > 80 | 晚上更可能在街上（散步、锻炼） |

### 为什么普通病要单独拎出来

- 有 **3%** 的人带有"慢性病/需要看医生"的日常需求，
  这会让他们**在爆发前去过医院**，于是医院门口在爆发初期就有人；
- 感染之后"发病 → 去医院"（M6）走的是另一条路径，
  但**表现是一样的**：人往医院跑 —— 于是医院从第一天起就是个可疑的热点；
- 这正是"零号病人"模式想要的效果：**平常的看病和致命的感染，在图上看起来一模一样**。

### 城镇规模差异

日常层的**人口流动量**按城市规模自动缩放：
大城市（柏林/东京）人多、通勤距离长；小县城（镇平）人少、活动半径小。
用现成的 `POI 数量 / 城市面积` 算一个系数即可，不需要额外数据。

## 十六、行动链：三步

> 按你说的，行动链显示成**三步**。既好看，也能表达"先干嘛、再干嘛"。

### 三条链

| 人群 | ① | ② | ③ |
|---|---|---|---|
| **平民（有家庭）** | 接家人（学校/家） | 回家取物资/枪 | 去警局避难 **或** 撤离 |
| **平民（无家庭/旅客）** | 回家取枪（有枪才走这步） | 去警局避难 **或** 撤离 | —（两步链） |
| **警察** | 回局领装备 | 出警 / 护送要员 | 回局坚守 |
| **要员** | 等待接应 | 随队转移 | 抵达警局 / 撤离城区 |

### 面板显示

```
行动链   ① 接家人 ✓   ›   ② 回家取枪 ●   ›   ③ 去警局避难 ○
                                    当前第 2 / 3 步
```

- `○` 未开始 / `●` 进行中 / `✓` 已完成
- 第三步是**分叉**（避难 or 撤离），由当时的混乱度与信任度在到达第二步时决定
- 链断掉时（家人死了 / 家里没枪 / 小队全灭）会**掉回危机层重新选**，
  面板上把断掉的那步标红并写明原因

### 链的推进条件

| 步骤 | 完成条件 |
|---|---|
| ① 接家人 | 到达家人所在处（学校/家）且家人存活 |
| ② 回家取枪 | 到家 且（拿到枪 **或** 家里没枪） |
| ③ 去警局/撤离 | 到警局 30m 内 / 踩到撤离线 |

## 十九、时间系统（时间段）—— 先有钟，再谈日程

> 第十五节的日程表是"空中楼阁"：游戏目前只有 `T+02:18`（**已过去多久**），
> 没有"现在几点"。这一节把钟定下来，日程表才有依托。

### 19.1 基本参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 一天长度 | **24 分钟**（1 游戏小时 = 60 秒） | 1× 速度下玩 20 分钟 ≈ 走完一个大半天 |
| 起始时刻 | **第 1 天 07:30**（可配：清晨 / 早高峰 / 白天 / 深夜） | 默认卡在早高峰前，开局就能看到人流 |
| 倍速 | 1× / 4× / 16×（已有） | 16× 下一天 = 90 秒；观察用，不是玩 |
| 时钟显示 | 顶栏 `第 1 天 08:24 · 早高峰` | 替换现在的 `T+mm:ss`（战报里保留总时长） |

**为什么是 24 分钟**：一场对局通常 10–30 分钟（1×）。24 分钟一天意味着
"一局 ≈ 一天"，正好是一个叙事单元：早上正常 → 中午出事 → 傍晚崩溃 → 夜里收场。
调成 12 分钟会变成"一天里跑两轮"，48 分钟则一整局都在早上。

### 19.2 时段划分（6 段 + 5 个锚点）

| 时段 | 时间 | 街上的人 | 主要行为 |
|---|---|---|---|
| **深夜** | 23:00–06:00 | 极少 | 在家睡觉；夜班在单位；急诊在医院 |
| **早晨** | 06:00–09:00 | 最多 | **通勤**（家 → 单位/学校）、买早饭、送孩子 |
| **白天** | 09:00–17:00 | 中等 | 在单位/学校；**12:00–13:00 午饭**（外出小高峰） |
| **傍晚** | 17:00–20:00 | 多 | **下班回家**、接孩子、买菜 |
| **夜晚** | 20:00–23:00 | 中等 | 在家；散步/购物/看医生（急诊） |

**锚点**（整点触发一次群体迁移，比逐分钟插值省事、也更可控）：

| 锚点 | 事件 |
|---|---|
| 06:30 | 起床 → 开始通勤 |
| 08:00 | 到岗/到校（绝大多数人到位） |
| 12:00 | 午饭外出（1 小时后回岗） |
| 17:30 | 下班 → 回家潮 |
| 22:30 | 回家睡觉（街上清空） |

> 时段决定"底色"（哪些目标可选、权重多少），锚点负责"集体动一下"。
> 这样不用每帧插值，也不会出现"所有人同一秒转身"的机械感（每人有 ±20 分钟的个人偏差）。

### 19.3 每段的日常行为权重

日常层（第十五节）的优先级表按这里实现：

| 目标 | 深夜 | 早晨 | 白天 | 傍晚 | 夜晚 |
|---|---|---|---|---|---|
| 睡觉（在家） | **1.0** | 0.1 | 0 | 0 | 0.4 |
| 通勤去单位/学校 | 0 | **0.9** | 0.2 | 0 | 0 |
| 在单位/学校 | 0.15※ | 0.3 | **0.9** | 0.2 | 0 |
| 回家 | 0.2 | 0.1 | 0.1 | **0.9** | 0.6 |
| 购物（超市） | 0 | 0.25 | 0.2 | 0.6 | **0.5** |
| 接孩子 | 0 | **0.5** | 0 | **0.8** | 0 |
| 去医院（普通病） | 0.35 | 0.3 | 0.35 | 0.3 | **0.4** |

※ 深夜在单位的是夜班（护士、地铁司机、保安）。

### 19.4 和已有系统的关系

| 系统 | 受影响方式 |
|---|---|
| **日常层 / 日程** | 完全按上面的表；`awareness ≥ 1` 或 `chaos ≥ 35` 时切到危机层，**时钟只影响"危机层里有没有人"** |
| **信息层** | 深夜目击少 → 知晓度涨得慢（已有感知逻辑，不需要改，只是人少了自然慢） |
| **警察** | 深夜在局里的是绝大多数（本来 90% 驻局）；巡逻警数量按"夜里少 30%" |
| **POI 营业** | 学校 07–17 才有人；超市 08–22；医院 24 小时；车站 24 小时 —— 直接用时段查表，不用改数据 |
| **零号病人模式** | 长潜伏（10–30 分钟）会**跨天**：可能白天被咬、半夜发病跑医院 —— 医院的夜间场景会很出戏 |
| **3D 光照** | 已有 `uNight` 参数：白天 0，夜里 0.6 线性过渡（19:00 起变暗，05:00 起变亮） |
| **2D 模式** | 夜里给整屏加一层很淡的蓝（透明度 ≤ 12%），不遮信息 |
| **战报** | 记录"第几天几点出事"、峰值出现在哪个时段 |

### 19.5 起始时刻的三种开局（给玩家选）

| 开局 | 起始 | 特点 |
|---|---|---|
| **早高峰**（默认） | 07:30 | 街上人最多，扩散最快，最"热闹" |
| **深夜** | 23:30 | 大多数人锁在家里，扩散慢，但救不了、也跑不掉 |
| **午后** | 14:00 | 人分散在单位/学校，适合看"分头行动" |

这本身就是一个玩法维度：**同一张地图、同一个爆发点，开局时间不同，结局完全不同。**

### 19.6 实现要点（很小）

```js
// sim 里只加三个数
this.dayLen = 1440;                 // 游戏秒/天（24 分钟 = 1440 秒，1 小时 = 60 游戏秒）
this.startHour = 7.5;               // 起始时刻
this.clock = (this.startHour * 60 + this.time * 60 / 60) % 1440;  // 游戏内分钟数
this.seg = segOf(this.clock);       // 0..5 时段
```

- `segOf()` 就是一个查表函数（半小时精度），**纯整数运算，零成本**；
- 日常层选目标时读 `this.seg` 查权重表；
- 不需要逐分钟模拟：锚点用"每天到点触发一次"的游标（`nextAnchor`），和现在的 `commuteAt` 一个套路；
- 现有的 `commuteAt`（每人 70–180 秒一轮）**被时钟日程取代**，这是这次改动最大的一处。

### 19.7 一个要注意的取舍

时钟一旦存在，**"快进观察"会变得很别扭**：16× 下一天只有 90 秒，
人会一直在赶路、永远到不了单位。

> 方案：**倍速 ≥ 4× 时，时钟不再按真实时间走，而是按"群体行为完成度"走** ——
> 即"通勤完成率到 90% 就跳锚点"。这样快进时看到的还是完整的一天，只是快。

## 二十、时间与日程的待定项

1. **一天 24 分钟**合不合适？（可调 12 / 24 / 48）
2. **起始时刻默认早高峰**，还是让玩家每次选？
3. **夜里要不要真的变暗**（3D 调 `uNight`、2D 加淡蓝）？会不会影响看情报？
4. **急诊 24 小时**：夜里发病的人也会往医院跑 —— 这会让"零号病人"常在半夜爆发，接受吗？
5. **快进时的时钟策略**：按真实时间，还是按"群体行为完成度"跳锚点（19.7）？
