# 血量与进化系统（草案 v1）

> 现在的血量只有一句话：`hp[i]` 是个数，打到 0 就死。
> 现在的"特殊丧尸"是固定表里随机冒出来的，和玩家做了什么无关。
>
> 这份草案把两件事拆开设计：**血量 = 个体有多能扛**，**进化 = 病毒有多会学**。

---

## 一、血量系统

### 1.1 人的血量：分成 4 个"状态"而不是一根条

纯数字血条在 2 万人的规模上没有可读性，改成分层：

| 状态 | 血量 | 表现 |
|---|---|---|
| **健康** | 100–75 | 正常 |
| **轻伤** | 75–45 | 速度 ×0.9、命中 ×0.9、**会流血** |
| **重伤** | 45–20 | 速度 ×0.6、命中 ×0.7、持续失血、**走不了远路**（寻路距离上限降低） |
| **失能** | 20–0 | 只能爬（速度 ×0.2）、**可以被救**、被丧尸追上必死 |

**失能**这一档是关键的：它把"救人"从抽象行为变成具体场景 ——
地上趴着一个还能救的人，你敢不敢过去（勇猛属性在这里起作用）。

### 1.2 命中部位（只在"人"身上生效）

开枪/被咬时掷一个部位，权重受距离、武器、熟练度影响：

| 部位 | 权重 | 效果 |
|---|---|---|
| 头 | 8%（狙击/近距离 +） | 人类**直接失能**；丧尸**直接死**（爆头） |
| 躯干 | 52% | 正常伤害 |
| 四肢 | 40% | 伤害 ×0.6，但**附加"肢体受伤"**：腿伤 → 速度 ×0.5；手伤 → 命中 ×0.5 |

熟练度高的人**更容易打头**（这条和已有的 `skill` 字段天然对接）。

### 1.3 流血与止血

- 轻伤以上开始**失血**：每 10 秒 −1 ~ −3 点血（重伤更快）；
- **绷带/急救包**可以止血（接上刚做好的物资储备：医院有，药店有，家里偶尔有）；
- 不止血 + 没人管 → **几分钟后自己死掉**（不是感染，是失血）；
- 血迹会**吸引丧尸**（复用噪音系统，改成"气味/血迹"）。

于是"受伤"变成一个独立的死因链：**中弹 → 流血 → 没人救 → 死**，
而不是"中弹 → 还在跑 → 被咬"。

### 1.4 丧尸的血量：两套语义

| 概念 | 含义 | 效果 |
|---|---|---|
| **血量** | 结构完整度 | 打到 0 = 彻底倒下 |
| **肢体破坏** | 打腿 → 只能爬（经典 crawler） | 速度 ×0.25，但**更隐蔽**（趴着不容易被发现） |
| **爆头** | 一枪致死 | 唯一"确定性击杀" |

再加一条长期变量：**分解度**（第 1 天 0 → 第 5 天 1）。
日子越久，老丧尸越慢越脆（速度 ×(1−0.5×分解度)、血量 ×(1−0.4×分解度)），
**但新变的永远是最新鲜的** —— 于是"老尸"和"新尸"在同一张图上是两种敌人。

### 1.5 和现有系统的接口

| 接口 | 改动 |
|---|---|
| 武器伤害 | `shoot()` 现在直接扣血 → 改成"掷部位 → 扣血 + 加伤情" |
| 熟练度 `skill` | 影响爆头率与止血速度 |
| 物资储备 | 新增"绷带/急救包"两个消耗品（医院、药店、警局都有） |
| 行为系统 | 重伤者优先去医院（`HELP` 的触发从"感染"扩展到"受伤"） |
| 救人行为 | 只在目标"失能"时触发，需要勇猛 + 意志 |
| 面板 | 血量条 + 伤情图标（腿/手/流血） |

## 二、进化系统

### 2.1 先明确一件事：谁在进化

有两种解读，**玩法完全不同**，需要你先定：

| 玩法 | 谁做决定 | 体验 |
|---|---|---|
| **A. 病毒自动进化**（导演制） | AI 按规则点技能 | 玩家是应急方，眼看着新威胁出现 |
| **B. 玩家扮演病毒** | 玩家点进化树 | **攻守反转**：玩家是疫情的导演，对面是城市 |

> 我个人推荐 **A 先做**（工作量小、和现有玩家身份一致），
> 把 B 作为"第二模式"另开一局（同一套数据，换控制方）。

### 2.2 进化点从哪来

| 来源 | 速率 | 用意 |
|---|---|---|
| 时间 | 每小时 +1 | 不做事也会慢慢变强（压力） |
| 感染人数 | 每 100 人 +1 | 规模换强度 |
| 击杀人类 | 每 20 人 +1 | 战斗换强度 |
| 混乱度 | ≥50% 时每小时额外 +1 | 城市越乱，病毒越顺 |
| **城市压制** | 疫苗/检疫/封锁 每生效一次 **−2** | 玩家的抵抗是有意义的 |

**关键平衡**：进化点与"城市反应强度"挂钩 —— **玩家压制得越狠，病毒进化越慢**。
这样玩家不是"越打越绝望"，而是"打得对就能拖住它"。

### 2.3 三条分支（每条 5 级）

**① 体能（Body）**

| 级 | 节点 | 效果 |
|---|---|---|
| 1 | 疾行 | 速度 +15% |
| 2 | 耐打 | 血量 +40% |
| 3 | **夜行** | 夜里速度 +30%、视野 +（配合已有的昼夜系统） |
| 4 | 抗伤 | 四肢伤害 −50%（不再容易被爬行） |
| 5 | **装甲** | 小口径伤害 −60%（必须用霰弹/步枪/爆头） |

**② 传染（Plague）**

| 级 | 节点 | 效果 |
|---|---|---|
| 1 | 强化唾液 | 咬伤潜伏期 1–2h → 40–80min |
| 2 | 接触扩散 | 传染半径 10m → 15m，接触时间 10s → 6s |
| 3 | **突破免疫** | 天然免疫 5% → 1% |
| 4 | 空气传播 | 密闭空间传染概率 ×3 |
| 5 | **水源污染** | 水体附近的人持续低概率感染 |

**③ 群体（Horde）**

| 级 | 节点 | 效果 |
|---|---|---|
| 1 | 集结 | 丧尸向最近的同类聚拢（不再零散） |
| 2 | 尖啸 | 新增"尖啸者"：周期性嚎叫，吸引 300m 内所有丧尸（复用噪音） |
| 3 | 协同 | 围攻时从多方向包夹（不再排队送死） |
| 4 | **伏击** | 静止不动时更难被发现（人类靠近才动） |
| 5 | 潮涌 | 全城丧尸向"人数最多的人群"缓慢汇聚 |

### 2.4 特殊个体（进化的"看得见"的部分）

不是每个节点都改数值，有些直接**解锁新的丧尸类型**（复用现有 `SPECIES` 表 + 现有 `special` 机制）：

| 类型 | 解锁于 | 特征 |
|---|---|---|
| 奔跑者 | 体能 1 | 速度 2.5×，血量低 |
| 爬行者 | 肢体破坏（被动产生） | 慢、隐蔽、难打中 |
| **尖啸者** | 群体 2 | 不咬人，只嚎叫招尸潮 |
| 装甲者 | 体能 5 | 正面免疫小口径 |
| 夜行者 | 体能 3 | 夜里强、白天弱 |
| **母体** | 传染 5 | 移动慢，但周围 30m 持续传染 |

### 2.5 可见性（很重要）

- 顶栏：**进化度 x/15 · 当前分支**（或者做成"未知"——玩家只能从现象推断，更恐怖）；
- 面板/战报：`第 2 天 14:00 出现奔跑者`、`病毒突破免疫屏障`；
- 地图：没有直接标识（保持"未知"的恐惧感），**只靠症状识别**。

我倾向：**数值面板可见，但"下一个节点是什么"不可见** —— 有悬念但不至于瞎猜。

### 2.6 反制手段（玩家的对策）

| 进化分支 | 玩家怎么对付 |
|---|---|
| 体能 / 装甲 | 换武器（霰弹、步枪、燃烧瓶）、爆头 |
| 传染 / 空气 | 口罩（降低飞沫）、检疫站、疫苗 |
| 群体 / 潮涌 | 路障、封锁、直升机撤离、诱饵 |

也就是说：**进化树应该逼玩家换策略，而不是把同一个策略堆到更强。**

## 三、两套系统怎么咬合

| 血量系统 | 进化系统 |
|---|---|
| 人类受伤 → 失能 → 被咬概率上升 | 传染分支让"被咬"更容易发生 |
| 丧尸肢体破坏 → 爬行者 | 体能分支让爬行者也变快 |
| 分解度：老尸变弱 | 体能分支抵消分解度（"不腐烂"） |
| 失能者可以被救 | 群体分支让救援更危险（围攻） |

一个很好的长线弧：
**第 1 天**人类还能靠数量扛、丧尸慢；
**第 2–3 天**进化出夜行/装甲，人类的"白天优势"消失；
**第 4 天**群体潮涌，撤离点被围；
**第 5 天**传染 5 级水源污染，连躲在家里都不安全。

## 四、数值草案

```js
HP = {
  humanMax: 100,
  tiers: [75, 45, 20],              // 健康 / 轻伤 / 重伤 / 失能
  bleedPer10s: [0, 1, 3, 5],        // 按状态
  bandageHeal: 15,                  // 一个绷带回复
  zombieMax: 12,                    // 保持现在的 12（一枪爆头 ≈ 直接死）
  headChanceBase: 0.08,
  headChanceSkill: 0.08 + 0.12 × skill,
  limbSlow: 0.5,                    // 腿伤减速
  limbAcc: 0.5,                     // 手伤掉准
  downedSpeed: 0.2,
  decayPerDay: 0.2,                 // 每天分解度 +0.2，封顶 1
}

EVO = {
  pointsPerHour: 1,
  per100Infected: 1,
  per20Kills: 1,
  chaosBonus: 1,
  suppressionCost: -2,              // 每次有效防疫
  branches: { body: 5, plague: 5, horde: 5 },
}
```

## 五、代价与风险

| 项 | 说明 |
|---|---|
| 血量系统 | 中等：`hp` 数组已存在，主要改 `shoot()`、加 3 个状态数组（伤情/流血/部位） |
| 进化系统 | 中等：加 1 个全局状态（进化点/节点）、几个 `SPECIES` 条目、少量 AI 修正 |
| **最大风险** | 进化容易**雪球**（越强 → 感染越多 → 进化越快）。必须靠"城市压制 −2"和"每天封顶"双向刹车 |
| 第二个风险 | 血量分层会让"击杀数"变慢，**节奏变慢**，需要和感染系统一起调 |

## 六、需要你定

1. **进化由谁点**：AI 导演（A）/ 玩家扮演病毒（B）/ 两者都做（不同模式）？
2. **血量用分层（4 档）还是真血条（0–100 连续）**？我建议分层，可读性高得多。
3. **命中部位**要不要做？（我建议做，它让"爆头"和"打腿"变成真正的战术）
4. **进化度对玩家可见吗**？我建议"当前分支可见、下一节点不可见"。
5. **分解度**（老尸变弱）要不要？我觉得这是很便宜、很出戏的一条。
6. 先做哪个：**血量**还是**进化**？（我建议先血量 —— 进化会依赖血量，而且血量让现有武器立刻有层次）
