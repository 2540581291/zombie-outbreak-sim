面向接手维护的开发者。本文只描述**当前代码事实**（括号里的 `js/main.js:123` 就是出处），与注释/历史设计不一致的地方单独标注。

## 0. 数据流总览

```
pointerdown ──┐
pointermove ──┼─→ drag{x,y,moved,btn} ─→ pointerup
```

## 1. 点击命中

| 阶段 | 位置 | 事实 |
|---|---|---|
| `pointerdown` | `js/main.js:260-264` | 建 `drag = {x,y,moved:0,btn,sx,sy}`；左键另存 `boxStart`；`setPointerCapture` |
| `pointermove` | `js/main.js:265-296` | 先 `hoverAt(e)`（`986`，投影地面预览环）；累积 `drag.moved += |dx|+|dy|`（`270`） |
| `pointerup` | `js/main.js:297-375` | 先算 `wasClick`/`wasRight`，再结算框选，最后才 `drag = null` |

判定阈值（三处，彼此不等价）：

- 左键点击：`drag.moved < 5 && btn === 0`（`js/main.js:298`）
- 右键下令：`drag.moved < 8 && btn === 2`（`js/main.js:299`）
- 左键框选：`drag.moved > 6`（拖动中 `js/main.js:276`，结算 `js/main.js:302`）

中间 5～6 px 是死区：既不算点击也不算框选，什么也不会发生。

命中流程（`js/main.js:349-374`）：`activeCamera()`（`1001`，2D 模式换成正交相机）→ Raycaster 打 `y=0` 平面 → 若当前工具 `kind==='select'` 则 `pickAgents(x,y,22)`，空则放宽到 44（`360-361`）→ **优先选"不是当前选中"的候选**（`366`，解决人群重叠时"点了没反应"）→ 有候选 `selectAgent`，无候选 `deselectAgent`。

`pickAgents(clientX, clientY, radius=22)`（`js/main.js:382-402`）：

```js
for (let i = 0; i < n; i++) {                    // 全量 O(n) 遍历
  if (st === ST.CORPSE || st === ST.SAVED) continue;   // 尸体/已撤离不可点
  v.set(sim.px[i], 0.9, sim.pz[i]).project(cam);       // 世界→NDC（y 抬到 0.9m）
  if (v.z > 1) continue;                               // 远平面外
  // NDC → 像素，屏幕外 40px 也算（留余量）
  if (d < r2) out.push({ i, d });                      // d = 像素距离平方
}
out.sort((a,b) => a.d - b.d);
return out.slice(0, 8);                                 // 最多 8 个候选
```

返回 `[{ i, d }]`（下标 + 像素距离平方，按近到远），**按屏幕距离而非世界距离**排序，所以拉远视角时 22px 能一次罩住十几个人——靠 `slice(0,8)` 和"跳过当前人"兜住体验。`pickAgent()`（`404-422`）是同逻辑单选版，**当前无人调用（死代码）**。

## 3. selectAgent / deselectAgent

`selectAgent(i)`（`js/main.js:533-553`）完整顺序：

1. `multiSel.size` 非空 → `multiSel.clear()` + `updateGroupBadge()`（`534`）
2. **同一个人**：`placeView = null` → `renderAgentCard()` → `return`（`535-540`）；注意这里**不会**把隐藏的卡片重新显示出来
3. `clearLink()`（`542`）——黑色连线
4. `pathKey = ''` + 隐藏 `pathLine`/`pathRing`（`543-545`）——清路径
5. `selected = i`（`546`）
6. `placeView = null`（`547`）——回到角色视图
7. `if (followSelected) rig.target.set(sim.px[i], 0, sim.pz[i])`（`548`）——跟随中直接对准新人（不插值）
8. 取 `#agentcard`，`classList.remove('hidden')`（`549-551`）
9. `renderAgentCard()`（`552`）

函数**没有** `!sim` 守卫，也**没有** `i < sim.n` 越界校验（见 §12-8）。

`deselectAgent()`（`js/main.js:600-606`）：`selected = -1` → `clearLink()` → `followSelected = false` → 卡片加 `hidden`。**不清 `multiSel`、不调 `updateGroupBadge`、不重置 `#ac-follow` 文案**（§12-4）。

触发点：点空白（`369`）、`#ac-close`（`1538`）、`重新爆发` 按钮（`1255`）。

## 5. 地点视图 renderPlace（当前不可达）

`renderPlace()` 在 `js/main.js:709-728`：读 `placeView`，写 `#ac-name`（地点名/类型）、`#ac-sub`（`类型 · 坐标 x, z`），隐藏 `#ac-vip`，body 里给「类型/面积/军械库/驻局警员/附近 50m 人数/离镜头距离」，警局额外查 `stockText(p.store)` 与 `sim.idleAt(si)`（`717-721`）。

## 6. 家属 chip

- 数据：`kinList(sim, i, ageOf, nameOf)`（`js/family.js:141-162`）。家庭是**平民数组上的连续区间**（`hhStart/hhEnd`），关系按年龄现算：成年且年龄差 <15 → `spouse`，i 成年而 j<18 → `child`，反之 `parent`，j≥60 → `grandparent`，其余 `sibling`。旅客（`sim.tourist`）和单人户返回空数组。
- 调用：`js/main.js:858-859`，动物与士兵/重装兵（`kind===4||5`）直接给空数组，理由注释是"住营房"。年龄取值 `sim.age[j]` 优先，回退 `ageOfAgent`。
- 文字映射：`ROLE_TXT = {spouse:'配偶', child:'子女', parent:'父母', grandparent:'祖辈', sibling:'同住'}`（`js/main.js:855`），未知角色回退「家人」（`875`）。
- 分组：按 role 各占一行（`869-876`）；无家属时回退 `p.family` 文本（`877`）。
- 死亡/尸变标记：`state===ST.CORPSE` → `†` + `gone` 类（删除线+半透明，`css/style.css:303`）；`state===ST.ZOMBIE` → `☠`；都写进 `title` 提示（`860-866`）。**`ST.SAVED`（已撤离）不标记也不禁用**，点到会连一条指向城外的线。
- 点击 = **连线**而非切换选中：`setLink('agent', j, 短名)`（`1575`），镜头不动、`selected` 不变，卡片多出「连线 → xx」一行；再点同一个 chip `setLink` 判定 same → `clearLink` + toast「已断开连线」（`558-561`）。`js/main.js:854` 的注释「点了选中他，镜头跳过去」是旧行为残留，与实现不符。

## 8. 选中圈

`ensureSelRings(n)`（`188-203`）维护 `selRings` mesh 池：`RingGeometry(1.15,1.7,24)`，青色 `0x7fe0ff`，`depthTest:false`、`renderOrder:8`，**上限 80**（`need = Math.min(80, n)`）。

`updateSelRings()`（`204-222`，每帧 `2196`）：

```js
const list = multiSel.size ? [...multiSel] : (selected >= 0 ? [selected] : []);  // 框选优先
if (i === undefined || state === ST.CORPSE || state === ST.SAVED) { hide; continue; }  // 无 continue 的旧 bug 已修
m.position.set(sim.px[i], 0.08, sim.pz[i]);
const sc = multiSel.size ? 1 : 1.15;   // 单选圈略大
```

即：多选时**只画 `multiSel`**（`selected` 那位的圈此时不单独画，因为 `selected` 也在 `multiSel` 里）；单人选时画 1 个。尸体/已撤离的圈隐藏（`213-216`），但 `selected` 本身不会被重置——卡片继续显示"尸体"。

## 9. 框选

`unitsInRect(x0,y0,x1,y1)`（`js/main.js:239-256`）：全量遍历 `sim.n`，**只收 `state === ST.SOLDIER`**，把 `(px,0.9,pz)` 投影到屏幕，落在矩形内即收入，返回下标数组。

结算（`js/main.js:302-319`）：`drag.moved > 6` 才算框选（否则走点击）；有结果时 `selectAgent(boxed[0])` → `multiSel.clear()` → 全部塞进 `multiSel` → `updateGroupBadge()`（`171-184`，屏幕左上角"编组 N · 右键移动"）→ toast。没有结果时只 toast「框选区域里没有可指挥的单位」。

与 `selectAgent` 的交互：`selectAgent(boxed[0])` 会先把 `multiSel` 清空（`534`）并清连线/路径（`542-545`），所以必须**在它之后**重新填 `multiSel`——现有顺序正确（`310-312`）。之后右键（`321-347`）按 `multiSel` 逐人 `sim.orderMove(ui, x+环形偏移, z+…)`，环形散开半径 3/6m，返回 `true` 才计数；`orderMove`（`js/sim.js:4301-4307`）对非 `ST.SOLDIER` 一律返回 `false`。`js/main.js:344` 用魔数 `3` 判断警察（应为 `ST.POLICE`）。

## 10. 跟随

`setFollow(on)`（`js/main.js:591-598`）：设标记 + 同步 `#ac-follow` 文案（「跟随镜头」/「停止跟随」）与 `.on` 类。

真正的跟随是**每帧硬设**：`if (followSelected && selected >= 0) rig.target.set(sim.px[selected], 0, sim.pz[selected]);`（`js/main.js:2277`），即水平瞬移式锁定，不做插值；`updateToolbar` 里还有一份同样逻辑（`1441-1443`）。`selectAgent` 切换选中时若正在跟随会立刻对准新人（`548`）。`zos:focus` 事件（`158-169`）会先把 `followSelected` 置 false，避免"点了别处又被拽回来"，并把位移塞进 `panPending` 由主循环指数衰减消化（`2187-2194`）。

## 11. 每帧强一致

```js
// js/main.js:2279-2280
if (selected >= 0 && cardShownFor !== selected) renderAgentCard();
```

设计意图是给"改了 `selected` 却忘了重画"兜底。但同一帧后面还有一段**无条件**的刷新：

```js
// js/main.js:2305-2310
if (sim && selected >= 0) { const cEl = …; if (cEl && !hidden) { try { renderAgentCard(); } catch(e) { window.__cardErr = … } } }
```

所以卡片实际上每帧都会重建一次 `bodyHtml`（靠 `lastCardHtml` 比较避免写 DOM），`updateToolbar` 里还有第三处（`1439-1440`，HUD 4Hz）。`2280` 的检查因此只在"`cardShownFor` 落后"时才额外触发一次，属于冗余保险。它真正的隐患是：`renderAgentCard` 里 `placeView` 早退（`833`）发生在 `cardShownFor = selected`（`835`）**之前**——一旦将来启用地点视图，`cardShownFor` 永远追不上 `selected`，`2280` 会变成每帧多一次的重复渲染。

## 12. 已知的坑 / 潜在 bug

按"会不会炸"排序。

1. **`people.js:73` 会抛 ReferenceError**：`case GOAL.FLEE: return 正在逃往侧出口;` —— 中文标识符不是字符串。选中一个社会目标恰为 `GOAL.FLEE(3)`（正在往撤离口跑）的人时，`profileFor → goalText` 抛异常；`selectAgent` 里那次 `renderAgentCard()`（`js/main.js:552`）**没有 try/catch**，异常冒到 `pointerup`，被 `js/main.js:42-45` 的 `window.error` 抓到后 `fail()` 会把加载层刷成红字并把 `document.title` 改成 `ERR …`。`1440`/`2308` 两处有 try/catch，只会把错误吞进 `window.__cardErr`。
2. **每帧 O(n)**：`people.js:155-157` 的 `vipEscort` 为了数护送人数 `for (let k = 0; k < sim.n; k++)`——只要卡片停在某个要员身上，就是每帧两万次循环。
3. **每帧两次无用扫描**：`js/main.js:844-845` 的 `homeP` / `workP` 算完从未使用（`placeNear` 要遍历 `sim.poiByKind` 全部 POI，`615-624`）。
4. **`deselectAgent` 清不干净**（`js/main.js:600-606`）：不动 `multiSel`、不调 `updateGroupBadge`、不重置「跟随镜头」文案。所以点空白后编组角标与选中圈还在，而右键下令又被 `321` 的 `selected >= 0` 拦住 → 整队失联；重新选中后按钮文案还是「停止跟随」（实际 `followSelected=false`），点一下像没反应。
5. **`‹ ›` 会选中已撤离者**：`step()`（`js/main.js:1543-1548`）只跳过 `ST.CORPSE`，没跳 `ST.SAVED`，而 `pickAgents` 是两者都跳（`391`）。
6. **逃跑行不看状态**：`fleeBlock`（`766-787`）只读 `sim.fleeMode`；`becomeZombie`（`js/sim.js:4549-4568`）不清 `fleeMode/fleeGoal`，所以一只已经尸变的丧尸卡片里可能写着「有目标逃跑 → 回家」。
7. **路径线不看状态**：`updatePathLine`（`469-495`）只判 `selected>=0` 和 `goal`，尸体/已撤离者仍会画出虚线；`n===1` 时 `setDrawRange(0, 2)` 会连出上一帧残留的第 2 个点（兜底只写在 `n===0` 分支，`487`）。
8. **换种子不复位选中**：`$('btn-seed')`（`1302`）与 `window.__zosRestart`（`1301`）只 `clearLink()` + `sim.reset()`，不像 `#btn-restart` 那样 `deselectAgent()`（`1255`）。新局人口变小后 `selected` 可能越界：`renderAgentCard` 里 `sim.px[selected]` 为 `undefined`，`921` 的 `.toFixed(0)` 抛 TypeError（被 `2308` 吞掉），选中圈/路径拿到 NaN。
9. **装甲车指挥不了**：`js/main.js:238` 与 `170` 的注释写「士兵/重装兵/装甲车」，但 `unitsInRect` 只收 `ST.SOLDIER`，而装甲车 `state = ST.POLICE`（`js/sim.js:3411-3413`），`orderMove` 也只认 `ST.SOLDIER`（`js/sim.js:4302`）。
10. **选中圈上限 80**：`ensureSelRings`（`188-203`）池子封顶 80，框选超过 80 个单位时多出来的没有圈，且分组角标数字仍显示真实数量。
11. **死代码/死变量**：`pickAgent()`（`404`）、`agentRules()`（`637-668`，卡片里的"规则行"其实来自 `attrBlock`+`explainBlock`）、`behaviorBlock()`（`671-677`）、`pathKey`（`431` 只写不读，`543` 写）、`renderPlace()`（§5）、`cardFrame`（`2157` 未使用）。
12. **CSS 悬空声明**：`css/style.css:315-316` 在 `.ac-row .link:hover{}` 之后多出 `padding:1px 6px; border-radius:999px; …}`，是纯声明块（无选择器），整段被 CSS 解析器丢弃 —— 家属/地点 chip 的胶囊内边距与圆角因此不生效。
13. **缺 `pointercancel`**：只有 `pointerdown/move/up`（`260/265/297`），指针捕获被系统打断时 `drag` 残留，后续 `pointermove` 会当成拖拽继续平移。

特殊身份处理一览（卡片侧）：**丧尸**可被点选（`391` 只排除尸体/已撤离），顶部显示「丧尸」，但身份块仍按 `kind` 给出平民职业、家属仍列出（带 †/☠），属性块走"撕咬/咬合间隔/追击半径"分支（`743-748`）。**尸体**只能从总览（`js/overview.js:160-165` → `window.__zosSelect`，`js/main.js:1271-1276`）选中，卡片显示「尸体/已死亡」、血量 0，但属性块仍打印移速/命中率，选中圈按 `213` 隐藏。**动物**（`kind 12/13`）姓名换成宠物名，`ac-sub` 显示「动物 · 流浪狗」，身份块只给"来历"，不给职业/家属（`888-889`）。**装甲车**（`kind 11`）既不算动物也不在营房名单里（`857` 只判 `4/5`），于是会显示"家属"和住址。
