逃跑独立成一个大类：即时逃跑 / 有目标逃跑（回家·警局·出城）+ 警局沦陷 + 状态栏显示

结构（sim.js 新增三个数组）：
  fleeMode[i]   0 无 / 1 即时逃跑（只想离开 40m 内的丧尸）/ 2 有目标逃跑
  fleeGoal[i]   0 回家 / 1 去警局 / 2 逃离城区（仅 fleeMode=2 有意义）
  stationLost[i] 1 = 亲眼确认过警局沦陷

两类逃跑：
  A. 即时逃跑：40m 内出现丧尸（已有触发），方向背离丧尸群；40m 清空即结束（mode 1 → 0）
  B. 有目标逃跑：进入后**粘住**，不再被日常通勤决策覆盖；被丧尸威胁时同样进 ST.FLEE，
     但安全后回到自己的目标继续赶路（mode 保持 2）

B 类的触发（decide 里）：没持枪，且 (aware >= 2 亲眼看见 || chaos >= 50)

三种目标由性格打分决定：
  sHome   = 家人>0 ? family*1.10 + 0.15 : -1
  sPolice = trust*1.60 + (1-courage)*0.50        ← 确认过警局沦陷就直接作废
  sEscape = (1-family)*0.35 + (1-trust)*0.35 + courage*0.20 + (无家人 ? 0.35 : 0)

警局沦陷：走到警局门口（<18m）时若 30m 内丧尸 >= 3，
  就把 stationLost 置 1、目标改成回家或出城，之后不再选"去警局"。

状态栏：
  · 顶栏新增「逃 N」，悬停显示：即时逃跑 x · 有目标逃跑 y（回家 a / 警局 b / 出城 c）
  · 卡片「属性」里多一行「逃跑」：即时逃跑 / 有目标逃跑 → 回家·去警局·逃离城区
    （确认过警局沦陷的还会标"改道"）

实测（3000 人 / 60 初始丧尸）：
  t=10s 即时=1 回家=2 警局=0 出城=4
  t=40s 即时=1 回家=2 警局=0 出城=16
  → "回家"和"出城"都会出现；"警局"目前很稀少，因为 trust 均值约 0.4，
    要 trust >= 0.55 左右才会压过"出城"。想让它更常见就调 sPolice 的系数。
