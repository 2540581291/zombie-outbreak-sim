选中逻辑体检：修一个断裂的 if 块 + 卡片与选中强一致

发现的 bug（updateSelRings，死代码级的断块）：

  if (cond) { m.visible = false;
  m.visible = true;                 ← 少了 continue / 收尾括号
  m.position.set(sim.px[i], ...)       visible=false 被下一行立刻覆盖
  ...                                  i 可能是 undefined → 位置写成 NaN
  }

后果：环池里那些无效的圈不会隐藏，而是留在上一次的位置上（NaN 时干脆不动），
画面上就同时出现「新选中的圈」和「旧位置的圈」，看起来像选中错位。

改法：改成标准三段式（判无效 → visible=false + continue；否则 set 位置与缩放）。

另外加一条强一致保险：
  · 新增 cardShownFor 记录「卡片当前画的是谁」
  · 主循环 if (selected >= 0 && cardShownFor !== selected) renderAgentCard()
  · renderAgentCard() 开头写 cardShownFor = selected
这样不管哪条路径改了 selected 却漏了重画，下一帧都会自动纠正。
