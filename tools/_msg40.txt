警察/士兵弹药打光 → 先去警局补给（逃跑优先级更高）

在 ST.POLICE / ST.SOLDIER 分支最前面加了补给检查（不看有没有目标）：

  if (ammo<=0 && mag<=0 && reserve<=0 && fleeMode !== 2) {
    取 stationOf 对应的警局：
      · 距离 > 16m  → setGoal(SHELTER, 警局) 并以 1.05 倍速往回走
      · 到 16m 内   → 从**共用弹药池**（station.store.a[武器id]）取
                      min(4 个弹匣, 存货)，装满弹匣 + 备弹，扣减存货
  }

优先级：有目标逃跑（fleeMode=2）> 补给 > 原地待命
  —— 正在逃跑的人即使弹药打光也不回去拿子弹。

原来的逻辑是"没子弹就 ST.FLEE"，现在只有三种情况才会跑：
  1) 正在有目标逃跑；2) 没有归属警局；3) 警局弹药也被取光了。

注意：这个检查放在分支最前面，所以不管他此刻在驻守、出警还是护送，
弹药打光都会先回局补给。
