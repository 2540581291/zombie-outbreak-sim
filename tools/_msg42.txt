运行时可以改墙/门窗，重开一局自动恢复原样

本来就有「游戏内图层编辑器」（C 键 / 地形面板旁边的编辑模式）：
可以在运行时把格子刷成 墙 / 室内 / 门 / 窗 / 水 / 围栏 / 围栏门 / 草地 / 空地，
改动会立刻影响碰撞、视线、门场和寻路。

缺的是「重开一局要回到原样」——之前编辑器的改动直接写进 nav.grid，
点「重新爆发 / 换种子」不会回退。

现在：
· 新增 restoreNavBase()：nav.grid.set(baseGrid) + 清空 ops + 删掉 localStorage 缓存 +
  重建门场（buildDoorField）
· baseGrid 是游戏启动、应用完 collision.edit.json 文件补丁之后的那份网格快照
· 三个重开入口都调用了它：
  - 「重新爆发」按钮
  - 「换种子」按钮
  - window.__zosRestart()

所以语义是：
  游戏内改动 → 立刻生效（可以边打边改地图）
  重新爆发 / 换种子 → 回到本局开局时的碰撞层（文件补丁仍然保留，它们属于"地图本身"）
