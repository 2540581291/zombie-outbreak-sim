撤离线：判定、目标点、UI 绿线统一到同一个位置

问题（之前四处各写各的，所以"绿线在哪"和"哪里算撤离"对不上）：
  escapeLine()    离边 30m（UI 用它画绿带）
  onEscapeLine()  离边 60m（判定越线）
  escapePoint()   离边 40m（人往哪走）
  UI 绿带         又写死 18m 再画一次

改法：新增 escapeOffset()，全链路都用它：
  偏移 = 垂直于撤离方向的那条边长度的 1%（最少 4m）
    · 北方/南方撤离 → 用地图宽度
    · 东方/西方撤离 → 用地图高度

  escapeLine()    → 绿线位置 = 边界 - 偏移
  onEscapeLine()  → 越过这条线就算撤离成功
  escapePoint()   → 目标点就在这条线上
  UI 绿带         → 画在同一个坐标，厚度 = max(12, 偏移×2)

实测偏移量：
  莱斯特 507m 宽 → 5.1m（绿带厚 12m）
  柏林   3162m 宽 → 31.6m（绿带厚 63m）

举例（用户给的情形）：50 宽 × 20 高，北方撤离 → 50 的 1% = 0.5m，
但保底 4m，所以线在离北边 4m 处。

test_chain 5/5。
