卡片：新增"当前行为"，行程永远显示；警察/丧尸的行为按真实分支拆开

【问题】
原来卡片只有"状态：在街上走动 / 已丧尸化 / 执勤中"这种大类，
警察的巡逻/执勤/出警/护送全混在一起；丧尸只有"已丧尸化"，
"行程"一栏只在平民通勤时才出现，其他情况直接消失。

【改动】
1) sim.statusOf(i)：按代码里真实的分支条件判定当前行为，返回 {tag,name,detail}
   · 警察/士兵：护送要员 / 回局补弹 / 出警途中 / 奉命撤回 / 驻防戒备 /
                现场交火 / 街面巡逻 / 离开驻地 / 驻地待命
   · 丧尸：撕咬猎物 / 锁敌追猎（跨全城）/ 追击猎物（带距离）/ 游荡寻食（带下次搜敌倒计时）
   · 潜伏期：潜伏（未尸变）+ 约 X 秒后尸变
   · 平民：有目标逃跑（回家/去警局/出城，警局沦陷会标注）/ 惊慌逃跑 /
          回家补弹 / 去警局避难 / 回家取枪 / 回家 / 去单位 / 待在原地 / 驻足 / 闲逛
2) sim.itineraryOf(i)：任何状态下都给一句话
   · 平民/警察：目标坐标 · 还有 X 米 · N 个路点
   · 警察额外带驻地名称和距离
   · 丧尸：追向 (x,z) —— 目标实时坐标
   · 死亡/撤离也有对应文案
3) 卡片"状态"一行改成「大类 → 具体行为 · 补充信息」
   例：执勤中 → 驻地待命 · 距驻地 7m ／ 已丧尸化 → 追击猎物 · 48m
4) 新增调试参数 ?pickrole=police|zombie|vip|dog|flee，直接选中第一个该角色看文案
