寻路不认"墙已塌"的问题：两处缓存没失效

1) 单位自己的路径（pathN / wpT）
   路径一旦算好就跟着走，墙塌了它不知道，照旧绕着那堵墙走 →
   在废墟旁边四处打转。
   现在墙塌时对 18m 内的所有非尸体/非撤离单位清空：
     pathN = 0 · pathIdx = 0 · wpT = 0 · decT = 0
   下一帧他们就会重新规划，直接穿过缺口。

2) 规划器的路径缓存（navWorld.planner.cache）
   缓存键是"起点格→终点格"，值是绕墙的路线；墙塌后这些路线全部过期。
   现在清空缓存（节流：最多 1.5 秒一次，避免连续塌墙时反复抖动）。

注意：NavGrid 是直接引用 nav.grid 的（grid.js: this.grid = nav.grid），
所以"格子变了"本身是立刻可见的，问题只出在上层缓存。
