卡片顶部新增「种族」行：人类 / 丧尸 / 丧尸狗 / 尸体 …

【需求】要能一眼看出这是人还是丧尸，动物也要区分狗 / 丧尸狗，位置要够靠上。

【实现】
1) sim.speciesOf(i) 返回 { label, cls, from, pet }
   人类（警察/士兵/重装兵/装甲车组会带后缀）
   丧尸（from: 人类尸变）
   已感染的活人（from: 未尸变）
   尸体（from: 已死亡）
   狗 / 猫（附 · 家养 / · 野生）
   丧尸狗 / 丧尸猫
   野兽
2) 卡片正文**第一行**就是「种族」，用彩色徽章：
   人类=蓝、丧尸=红、已感染=黄、尸体=灰、野兽=橙，14px 加粗
   下面紧跟一条分隔线，再进入「身份」区
3) 动物身份区原来的「种类：狗（动物）」和种族行重复，改成
   「来历：有主人的猫 / 街头的狗，没有职业」

【实测】
  丧尸：种族 [丧尸] · 人类尸变
  警察：种族 [人类] · 警察
  猫：  种族 [猫] · 家养      来历 有主人的猫，没有职业
  狗：  种族 [狗] · 野生
  尸体：种族 [尸体] · 已死亡
