修「缩小到全城时有人不显示绿点」：3D 远景不再用近处模型层遮住点阵

【检查结果】
· 点阵本身**没有数量上限**：AgentRenderer 每帧 `setDrawRange(0, sim.n)`，
  数组按 160000 分配，绿的/红的都来自同一个点云，不存在"只画前 N 个"。
· 真正的坑在**近处模型层**：
    `agents.nearRadius = clamp(rig.dist * 0.9, 110, 1400)`
    `agents.unitsVisible = !retroMode`
  于是 3D 模式下即便把镜头拉到全城，镜头中心 1400m 内的人仍然被当成"近处"
  去画 3D 小人，并且 `hide[i] = 1` —— **这些人的点被主动隐藏了**。
  而全城视角下 3D 小人只有亚像素大小，看上去就是"这一片人凭空消失"。
· 2D 模式本来就 unitsVisible=false，所以 2D 下没有这个问题
  （截图验证：全城视角下绿点铺满，中心没有空洞）。

【修法】
main.js 每帧更新时加一条：视距超过 700 就在 3D 下也整片退回点阵
    if (!retroMode) agents.unitsVisible = rig.dist < 700;
700 是"还能看清小人"的上限，超过它就没必要再用模型层。

【验证】
· 2D 全城（?dist2d=26000&ff=6）：整张图绿点连续，中心区域没有空洞
· test_chain 5/5，页面正常启动

【附：如果你想自己确认 3D 情况】
打开 3D（Tab）后用滚轮拉到最远，看镜头中心那片是否还有绿点；
修复前那里是"只有 3D 小人、没有绿点"，修复后应当全部变成绿点。
