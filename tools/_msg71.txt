原版 15 张 Google 地图全部导入并验证通过

流程（tools/pull_google_maps.py）：
  1) 从 3DS MapConfig 读 worldX/worldY（z20 Web Mercator，世界宽 2^28）+ width/height
  2) 从 APK 读 assets/data/collision_layer_<id>.cl（zlib，解压后 500x500 或 1000x1000）
  3) 用 worldX/Y 反算 bbox：merc→lat/lon；米制按 z20 像素 = 156543.03*cos(lat)/2^20
  4) 从 Esri World Imagery（公开，无需 key）拉 z19 瓦片拼图（25 或 81 块/张）
     裁到 bbox 后缩放到原生分辨率（2000x2000 或 4000x4000）
  5) 碰撞表值映射 + 上下翻转 + 室内连通域合成建筑
  6) 写 city.json / sat.jpg / sat.json，登记 index.json
