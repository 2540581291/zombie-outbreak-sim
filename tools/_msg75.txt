UI 整体随窗口缩放：这次真的做了（之前只有顶栏会缩）

实际情况（查完）：
  topbar.css  有 clamp + vw，顶栏一直会缩放
  其他 5 个 css（style/panel/modal/gov/news）全是固定 px（716 处），完全不会缩
  → 所以"整体 UI 随窗口缩放"之前并没有实现

本次改造：
1) 6 个 css 里 716 处 px → rem（跳过 @media/@keyframes 和 1px 细边框）
   style 359、modal 128、gov 87、panel 60、topbar 45、news 37
2) style.css 加根字号随视口缩放：
     html{font-size:clamp(10px, 1vw, 26px)}
     1600px → 16px（1.0×）；1200px → 12px（0.75×）；2560px → 25.6px（1.6×）
3) 顶栏字号从 "clamp(0.59rem, 0.625vw, 1.5rem)" 改成 0.75em
   —— 否则根字号缩放和顶栏自己的 vw 会叠加成二次缩放

效果：
  1600×900 下 UI 和之前一样大（截图 shots/scale3.png）
  758 宽下整块 UI（顶栏/面板/工具栏/弹窗）等比缩到 0.625×（shots/scale2_1600.png）
  test_chain 5/5
