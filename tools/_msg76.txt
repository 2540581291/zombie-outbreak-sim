UI 自适应：不再靠"缩小界面"硬塞，改成顶栏换行 + 根字号随窗口

问题：顶栏是单行不换行布局（overflow:hidden），1600 宽时右侧的
政府/武力/卫生/总览/战报/2D/地形 会被直接裁掉 —— 之前先试过"整体缩小"，
但算出来需要缩到 0.73 才能塞下（字号只剩 8~9px，没法看）。

最终方案：
1) 顶栏允许换行：#topbar{flex-wrap:wrap;height:auto;overflow:visible}
   → 窄窗口下第二行放按钮，所有内容始终可见
2) 根字号随窗口宽给可读值：px = clamp(10, 窗口宽/120, 22)
   1600 → 13.3px，1100 → 10px，2560 → 21.3px
   （不再做"缩到刚好装下"的强制压缩）
3) 面板正文自己滚动（#panel 限高 100vh-2.5rem，#p-body overflow-y:auto），
   不再为了它的高度去缩小整个 UI

实测：
  1600×900  顶栏单行完整（含 2D 模式/地形），面板完整
  1100×760  顶栏自动换成两行，按钮全部可见；面板完整
  test_chain 5/5
