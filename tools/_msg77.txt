顶栏强制单行 + 纯 CSS 自适应缩放（不换行、不裁切）

之前两次都没做对：
· 第一次用 JS 量 scrollWidth 再缩，测量把 overflow 的空白也算进去，
  算出来要缩到 0.73 倍（字号只剩 8px）还装不下；
· 第二次改成"允许换行"，能显示全，但不是你要的。

最终实现（纯 CSS，零测量误差）：
  实测：16px 根字号时顶栏内容宽 ≈ 1797px，即"内容宽 ≈ 112 × 根字号"
  所以令  根字号 = 视口宽 / 118  （留 5% 余量）
    html{font-size:clamp(5.5px, calc(100vw / 118), 22px)}
  顶栏强制单行：flex-wrap:nowrap; overflow:hidden; white-space:nowrap
  所有 UI 尺寸都是 rem/em → 整块界面等比缩放，顶栏永远恰好装下。

效果：
  1600 宽 → 根字号 13.6px，顶栏单行完整
  1100 宽 → 9.3px，完整
   758 宽 → 6.4px，依然单行完整（包括最右的 2D 模式 / 地形）
  2560 宽 → 21.7px（上限 22px）

JS 里的测量逻辑（fitUiScale/scheduleFitUi）已全部删除，避免和 CSS 打架。
test_chain 5/5。
